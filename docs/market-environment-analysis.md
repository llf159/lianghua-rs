# 市场环境分析

市场分析页的“市场环境”块直接读取原始前复权日线，在参考日截断后即时计算全市场等权环境。它不需要配置 `ind.toml`、不需要生成市场指标，也不读取已落库的指标值。

首屏概括市场整体方向、上涨是否覆盖多数股票、上攻成果能否保留，以及下探后的抵抗与修复。它不预测指数点位，不合成看多总分，也不自动调整策略权重。

## 数据与参考日

- 行情来源：`stock_data.db` 中 `adj_type = 'qfq'` 的日线。
- 交易日索引：`trade_calendar.csv`。所有滚动窗口与“近5日变化”都按市场交易日计算，不按自然日，也不跳过缺失记录。
- 上市资格：`stock_list.csv` 中上市满 60 个交易日的股票。上市日期缺失、无法解析，或行情库中存在但不在清单里的股票不纳入计算，单独计入“上市资格未知”。
- 读取窗口：参考日及之前 80 个交易日。该窗口覆盖 20 日个股基线、20 日共同波动、相邻 5 日领涨组、5 日平滑与 5 日变化。
- 最新行情日只表示行情库中存在报价的最新日期，不代表全市场都已更新。

## 覆盖与回退

每个候选分析日先计算“应有样本”和“有效报价”：

- 应有样本：参考日已上市满 60 个交易日、未在参考日前退市的股票。
- 有效报价：应有样本中当天存在前复权日线的股票。
- 推断停牌或缺口：当天无报价，但此前 20 个交易日内有报价。这里没有独立停牌表，因此属于推断，不称为“已确认停牌”。
- 行情缺失：当天无报价，且此前 20 个交易日内也没有报价。

当天覆盖率至少 90%、应有样本至少 20 只时才选为分析日。历史每日截面也按此规则检查；不足的日期留空，不跨过缺失日期平滑或计算变化。否则向前最多回退 20 个交易日，取最近覆盖充分的交易日，并在页面显示实际分析日与回退原因。回退后所有证据和摘要都使用同一个分析日，不混入最新日的零散报价。

历史参考日的应有样本来自当前 `stock_list.csv`。该文件只含当前清单中可确认的股票，已退市股票无法补入，因此历史日覆盖率主要用于判断当日行情是否完整，不等同于完整历史成分还原。

## 全局判断与近期进退

首屏给出一句判断、5／10日等权涨跌、近10日上涨股票比例和三段短论述。整体方向沿用10日方向顺畅度的±0.2解释刻度；近5日涨跌用于识别上行中的回撤、下行中的反弹。上涨股票比例按每只股票最近连续10个市场日的累计涨跌计算，不将市场均值上涨等同于多数股票上涨；连续窗口有效样本至少20只且覆盖当天有效收益样本的90%，不足则留空。

近期进退按近5个市场日内已经观察到的事件汇总：

| 观察 | 事件分母 | 成功的含义 |
| --- | --- | --- |
| 上攻站稳 | 盘中高点超过此前20日高点的事件 | 收盘仍高于该参考位 |
| 下探收回 | 盘中低点跌破此前20日低点的事件 | 收盘回到或高于该参考位 |
| 成果保留 | 前日已经上攻且收盘站稳、次日有连续有效行情的事件 | 次日收盘仍高于前日所用参考位 |
| 跌破修复 | 前日已经下探且收盘跌破、次日有连续有效行情的事件 | 次日收盘回到或高于前日所用参考位 |

上攻与下探的参考位只读事件发生前的连续20市场日；次日观察固定使用前日的参考位，不因新低移动修复线，不跳过停牌/缺行寻找“下次报价”。次日结果记在结果当天，参考日之后的结果不参与当日分析。

每类比例为5日成功次数之和除以事件次数之和，至少50次事件才解释比例；这个门槛用于避免少量事件使读数剧烈跳动，不代表置信水平或预测有效。展开区同步显示成功/全部次数、不同股票数，以及与前5个市场日窗口的比例差（百分点）。同一股票可贡献多次事件，次数不等于股票数；不同类型的分母是不同群体，不将两类比例相减作为多空分数。

论述可以指出“多数下探当日收回，但多数既有跌破次日仍未修复”等已发生事实。“过半”仅按观察比例的字面含义解释，不意味着未来胜率。反转概率单独估计，不改变这部分事实论述，也不自动调权；运行不依赖研究脚本和研究结果文件。

## 未来5日反转概率

首屏在整体处境之后展示带方向的反转概率，属于模型估计。当前10日方向顺畅度低于−0.2时估计向上反转，高于0.2时估计向下反转；震荡时没有明确原方向，显示“不适用”。上行中的回撤仍按上行背景，下行中的反弹仍按下行背景。

“形成并站住”要求未来第4、第5个交易日的10日方向顺畅度都越过相反方向的±0.2刻度，且这两日等权市场收盘都越过分析日固定参考位。结果在第5日收盘后可知。它要求整体方向改变，不把仅价格大幅反弹、但10日方向仍向下的V形计为已完成反转，也不代表长期牛熊切换。

估计按可用信息依次选择：

- 完整证据模型：输入10日方向、5日及当日价格运动、10日上涨股票比例、四类近期进退比例。该分支保留至少200个完整训练日、两类结果各20日的支持条件。
- 收缩价格模型：完整证据模型的训练支持或当日特征不足时，只使用10日方向、5日及当日价格运动。价格收益除以20日市场日收益样本标准差；至少60个价格完整训练日，取消每类必须20日的限制。标准化后的斜率L2=4，截距加入各半个成功/失败的惩罚，限制小样本或单类结果导致的极端参数。
- 历史频率估计：价格输入或回归支持仍不足时，使用同方向已有成熟标签的 `(成功日数+0.5)/(历史日数+1)`，明确标注估计方式。没有实际历史样本时仍显示数据不足。

三者估计相同反转事件；历史频率只按原方向分组，未按今日强弱细分。小样本不再直接阻断所有概率，也不以0%或50%作为缺失占位。上涨、下跌分别估计，不互为补数。百分比保留一位小数，极小/极大估计显示“<0.1%”或“>99.9%”，避免舍入成确定发生或不发生。

模型参数作为版本化JSON随软件提供，按季度冻结，只使用生效日前已经成熟的标签；参考日选取不晚于实际分析日的最近模型。季度末是建议复核日，超过时仍返回原模型估计并提示更新，不能视为已重新训练。设备不会在刷新时自动重训；更新训练样本需更新包含新资产的软件版本。历史查询不会使用之后的系数或评价支持。

所有输入与首屏共用实际分析日及覆盖回退。震荡显示“不适用”，无法读取模型或没有历史样本显示“数据不足”；这两种情况与“小样本但已有估计”区分。展开区列出本次方法、实际使用的训练日/成功日数、标签截止日、建议复核日和此前该方向整套估计流程的评价支持。价格模型不把未使用的进退事件列为模型贡献，历史频率不列特征贡献。

“模型估计”不等于概率刻度已经可靠。连续市场日期的未来窗口存在重叠，股票事件次数不是独立反转样本；贡献单位为对数几率，不是百分点或因果影响。

## 补充环境读数

所有截面计算先取上市满 60 个交易日且当天有有效报价的股票，再聚合为市场日序列。

| 维度 | 原始定义 | 展示单位 | 解释边界 |
| --- | --- | --- | --- |
| 方向顺畅度（10日） | 近10日等权市场对数收益之和 / 绝对值之和 | 无量纲 | 接近 +1 为向上推进，接近 -1 为向下推进，接近 0 为来回折返；不是涨幅 |
| 强弱延续度（5日） | 前一天为止的5日收益最强20%与最弱20%，当天开盘到收盘收益差，再取5日均值 | 个百分点 | 正值为原强势股相对更强，不表示市场看涨 |
| 收盘位置（5日） | 个股 `(2C-H-L)/(H-L)` 的日截面均值，再取5日均值 | 无量纲 | 正值偏日内高位；`H=L` 或 OHLC 无效时剔除 |
| 量价配合（5日） | 当日涨跌幅与“成交额/此前20日均额”的截面秩相关，再取5日均值 | 无量纲 | 正值表示相对放量更偏上涨股；不是资金净流入 |
| 领涨保留（5日） | 相邻两段不重叠5日收益最强20%成员的 Jaccard，再取5日均值 | % | 高为领涨群体保留，低为轮换 |
| 成交集中（5日） | 成交额前10%股票占全市场成交额比例，再取5日均值 | % | 描述成交分布，不是持仓拥挤度 |
| 交易冲击（5日） | `ln(max(|涨跌幅|,0.01)/成交额)` 减个股此前20日均值，当日取中位数，再取5日均值 | 无量纲 | 正值表示单位成交额对应波动高于自身常态；不能区分流动性与波动原因 |
| 共同波动（20日） | 20日市场等权收益方差 /（该方差 + 20日平均个股截面方差） | % | 高为共同冲击相对更强，不是精确平均相关系数 |
| 下跌尾部（5日） | 跌超3%股票比例减涨超3%比例，再取5日均值 | 百分点 | 正为下跌尾部占优。分母只含有效涨跌幅样本 |
| 大小盘分歧（5日） | 小市值与大盘组等权日收益方向相反的比例，再取5日均值 | % | 只描述是否分化，不判断随后谁领先 |

市值组沿用研究口径：`成交额 / 换手率 / 1000` 小于 100 为小市值，大于等于 500 为大盘，中间组不参与分歧计算；组内至少 20 只股票。

## 与原研究脚本的差异

正式实现沿用原始研究公式，但修正了两个边界：

- 上市日期缺失的股票不再按“很早上市”处理。它们不进入样本，并计入“上市资格未知”。
- 下跌尾部的分母只包含有效涨跌幅。缺失收益不参与阈值比较，也不稀释比例。

因此引用旧研究报告的具体读数时，需要按修正口径重新核对；不能为逐值一致而保留这两个缺陷。

## 页面使用

在市场分析页设置参考日后，点击“刷新环境”：

- 首屏用整体方向与参与范围、上攻及成果保留、下探及跌破修复三段简短论述解释当前局面。
- 点击“查看判断依据与数据”展开四类近期事件、样本覆盖和前后变化；原有十个环境读数与短历史放在第二层折叠区。
- 参考日或数据仓库改变后，旧结果立即清空；晚到的旧请求不会覆盖新结果。

全局判断描述截至分析日已经出现的组合状态，各维度保留各自含义，不按正负数量投票。另列的反转概率估计上述方向事件，不是普通未来上涨或收益概率。

如果最近21个交易日（含最新日）都没有覆盖充分的行情，页面只显示覆盖与原因，不生成方向或尾部结论。

## 常见数据问题

- 提示读取交易日历失败：确认数据目录存在 `trade_calendar.csv`，并在数据下载页更新交易日历后再刷新。
- 覆盖率持续低于 90%：先在数据下载页补齐前复权日线；如果只是最新行情日尚未更新，页面会回退并标明实际分析日。
- “上市资格未知”大于 0：检查 `stock_list.csv` 的 `list_date` 是否为空或格式不是 `YYYYMMDD`。这些股票不会进入计算。
- 页面显示“行情缺失”而非停牌：说明该股票在分析日及此前20个交易日都没有报价，应先在数据完整性检查中补齐该股历史。
