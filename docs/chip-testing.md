# 筹码单股测试

在“筹码测试”页选择股票、日期和筹码策略后运行计算。结果只保存在本次页面的临时结果中，不代表真实账户持仓，也不会重建正式筹码库。

## 独立基础成本V1

每次单股计算都另外返回基础成本。它独立于身份策略，使用同一日线成交分配和网格：已有库存按实际换手等比例扣减，再加入当日成交成本。它是日线成本代理，不是实际账户持仓。

- K为模拟期间成交形成、目前仍存活的成本质量，按全部流通总体计量；分桶不会重新放大成100%。
- U为没有确定价格位置的起点前库存，始终满足K+U=1。
- 条件均价仅对K计算，K为空时显示缺失；各桶中点处累计分布范围为`[累计K, 累计K+U]`，收盘价处为获利盘范围。这不是置信区间。
- 基础结果包含模型版本、模拟起点、前复权坐标与输入指纹。指纹仅用于本机结果核对，不是数据真实性认证。

所有股本变化统一采用比例继承假设：新增流通、解禁、送转、定增等都不再要求用户分类，也不在股本变化当天修改K/U比例；只继续执行当天实际换手迁移。这个假设不表示新增股份的真实成本已被观测，也不表示解禁持有人一定是散户。

基础计算仍用VOL/TOR及存储舍入精度作数据质量诊断。明显跳变只提示“疑似流通股本变化，按比例继承处理”；缺失成交量或换手率过小也会提示无法核对总体。这些提示不阻断K/U、条件均价和获利盘范围发布。明确的零量零换手日保持库存。

所有结果仍标为“条件估计／未完整核实”，不称已认证无事件，也不把日线成本代理称为真实账户成本。

## 库存记忆模式

正式配置见 [中档筹码策略](chip-inventory-memory.toml)。在策略资产中导入该文件，再恢复为当前筹码策略。策略管理页显示“库存记忆策略”，单股测试结果和历史按钮也标明库存记忆；编辑保存会保留模式版本。此配置需要支持 `version = 2` 的软件，旧版软件会拒绝加载。

库存记忆保留成本桶的卖出与成交价格分配，先以当日主力卖出量除以总换手作为中性买方比例，再叠加方向信号。无方向证据时主力占比保持，成本分布仍随交易更新。版本2的主力买入 `bias` 是可正可负的方向证据，零表示中性；多个触发项相加，不再使用旧版基础买方权重，散户买入比例自动取余量，卖出规则的 `bias` 含义沿用旧版。版本2禁止散户买入规则及后验归属修正。

库存记忆采用85%承接软目标、10%退出软目标、强度4，负证据倍率默认3。版本2可在 TOML 顶层、首个 `[[strategy]]` 之前设置 `negative_evidence_scale = 1.0` 等非负有限数值；省略时沿用3，0表示不因净负证据改变身份总占比。倍率作用于多条买方证据相加后的净负值，正向证据和卖方规则不受此参数直接调整。策略页显示当前倍率，编辑保存、单股测试及留存查询都会保留它。使用此字段的设备须先更新到支持该字段的软件；早期版本2软件会忽略未知字段。

软目标不构成持仓硬边界；新增买方比例限制在0到1，身份变化受当天成交和实际卖出库存约束。该模式是行为库存估计，无信号保留历史状态，低换手下初始50/50的影响可能持续，不能作为真实账户持仓观测。修改倍率会改变策略指纹，需要按下述流程重建历史；仅升级软件且配置不变时，默认行为和原指纹保持不变。

切换后需要从历史起点全量重算新筹码。策略指纹会识别版本变化，旧检查点及不匹配的重建暂存不能继续用于库存记忆；未选择重建时保留原结果。策略配置的导入、恢复和保存本身不执行重算。在新版本软件和库存记忆配置就绪后，到计算页运行“新筹码计算”，使用完整历史范围；本次重算由用户手动执行。依赖筹码字段的评分结果需要随后按需重算。

## 模型持仓年龄与固定区间留存

单股测试每个快照都会显示混合库存的年龄分布：0—4、5—19、20—59、60—119、120+报价日和初始年龄未知。分母为全部模型库存；初始未知始终单列，120+包含所有更长年龄。有效零换手报价也推进年龄，无报价停牌日不推进。年龄来源于成本桶内等比例出库账本，不表示主力持仓年龄，也不能与基础成本K/U、按主散分别扣减的初始来源互换。

页面同时显示实际观察起点及次数。旧检查点未记录起点时明确显示未知，不重设起点；旧临时结果没有摘要时需要重新计算。年龄分布从首个完整状态即可显示，表达式字段另外要求成熟观察长度：

| 表达式字段 | 全部库存的百分点（0—100） | 最少有效报价观察 |
| --- | --- | --- |
| `CYQ_AGE_NEW5` | 0—4日成交形成库存 | 5次 |
| `CYQ_AGE_KNOWN_GE20` | 20+日成交形成库存，不含初始未知 | 21次 |
| `CYQ_AGE_INITIAL` | 混合年龄账本的初始未知库存 | 1次 |

摘要有独立版本，沿现有批次落库，不改变原筹码或时长状态版本。旧历史行保持NULL，单股临时计算不会补齐正式库；兼容检查点只能生成后续日期摘要。需要历史读数时，使用现有新筹码历史维护入口从可重放起点向前计算，不能从最新检查点倒推。缺失、版本不兼容或观察不足都为空，实际零值仍为零。字段只有被表达式引用才会加载；添加这些字段不会自动启用年龄评分规则。

展开“固定成本区旧筹码留存”，输入锚点收盘日期、评价日期及前复权成本上下界，勾选后随单股计算查询。区间取与输入范围相交的锚点整桶，返回实际边界，此后边界固定。查询在生成绘图快照的同一次原生重放中捕获端点，只额外保留冻结的桶边界和端点汇总，不再重复重放或保存历史年龄矩阵，也不写正式库。单独的原生留存查询入口则只推进到评价日。

质量按每100份模型库存计量。输出包括锚点质量、旧批次剩余、区间当前总量、锚点后补入、留存率和补入占比。原区100份卖出60份又买入60份时，总量仍为100，旧批次只剩40，补入60。初始未知参与事件存活，但不变成已知年龄；零分母的比率为空。

两个端点必须位于同一次模拟的有效报价中。间隔为报价更新次数，0和120都可查询，超过120返回不可用原因；合并的120+档无法辨认更久的事件批次。结果带模拟起点、预热、网格和完整策略身份，股票及复权坐标随单股结果返回。改变模拟起点、策略或坐标后的结果不能视为同一库存历史。此查询没有接入跟踪评分，也不代表年龄条件已经通过收益验证。
