# 实时监控

在实时监控页的参数设置中，可以调整刷新间隔，并切换“腾讯 + 新浪分批并发”（默认开启）。开启时，股票分批由两源并发抓取，每批缺失或失败时向另一源补抓；关闭后使用全局设置中的单一行情源。指数与股票请求并行。

两源的成交量统一为手、成交额统一为元。新浪均价按成交额除以成交股数计算；新浪没有现成量比，盘中使用本地行情日前最近五根有效有成交日线的平均成交量：

`量比 = 当日累计成交量 ÷（五日平均日成交量 × 已交易分钟数 ÷ 240）`

已交易分钟数不包含午休，09:30近似为1分钟。本地五日均量不足时留空。已有分时基准时，两源都沿用该基准计算量比及高点。无分时基准时，午休、盘后不将新增累计量直接套入上述公式，量比可能暂缺。腾讯自带量比在基准补齐前仍可显示，补齐后使用统一基准。

“量比拉取”负责补齐开盘五分钟及当天分时基准；分批并发开关不等于开启分时补齐。当前量比可由累计量计算，开盘高点和日内新高判断仍需要有效分时基准，不能用当前量比替代。

点击“本轮 X 秒”可查看股票请求、量比、本地数据、指数及界面耗时。股票和指数的请求耗时相互重叠，不能直接相加。刷新间隔控制尝试启动下一轮的频率，在途请求未结束时不会叠加新一轮请求；切换来源从下一轮起生效。
