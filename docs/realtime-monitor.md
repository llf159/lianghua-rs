# 实时监控

在实时监控页的参数设置中，可以调整刷新间隔，并切换“腾讯 + 新浪分批并发”（默认开启）。开启时，股票分批由两源并发抓取，每批缺失或失败时向另一源补抓；关闭后使用全局设置中的单一行情源。指数与股票请求并行。

两源的成交量统一为手、成交额统一为元。新浪均价按成交额除以成交股数计算；新浪没有现成量比，盘中使用本地行情日前最近五根有效有成交日线的平均成交量：

`量比 = 当日累计成交量 ÷（五日平均日成交量 × 已交易分钟数 ÷ 240）`

已交易分钟数不包含午休，09:30近似为1分钟。本地五日均量不足时留空。已有分时基准时，两源都沿用该基准计算量比及高点。无分时基准时，午休、盘后不将新增累计量直接套入上述公式，量比可能暂缺。腾讯自带量比在基准补齐前仍可显示，补齐后使用统一基准。

“量比拉取”负责补齐开盘五分钟及当天分时基准；分批并发开关不等于开启分时补齐。拉取开关关闭时隐藏八个来源状态；没有待补或重试任务（已补齐或剩余股票缺少本地数据）时自动关闭，更新本地数据后可重新开启。当前量比可由累计量计算，开盘高点和日内新高判断仍需要有效分时基准，不能用当前量比替代。

量比分时补齐由腾讯、东财、MSN、同花顺、雪球、上交所、深交所按市场范围分流，单股成功后结束，失败再换源。每源固定 4 个独立工作线程，总计最多 28 个在途请求，各源从共享待办中领取适用股票，每源启动间隔至少 60 毫秒，遇到限流独立冷却退避。MSN 在当天 09:50 后参与沪深股票补齐；实际速度取决于接口耗时、成功率及登录会话的传输能力。

开启量比异动的“系统通知”后，同轮异动合并通知，最多列出五只股票的量比与“五日优”。通知中的“五日优”取总榜五日最佳排名和相似榜排名中更靠前的有效名次（数字更小），两者都缺失时显示空缺标记。

Android 使用独立的“量比异动”高重要性通知渠道，每轮新异动替换上一条通知并重新提醒。通知权限只决定能否发送；悬浮显示还取决于渠道设置与勿扰模式。安装更新并触发一次异动后，可长按通知进入“量比异动”渠道设置，开启“悬浮通知／横幅／在屏幕上弹出”（具体名称随系统变化）。

点击“本轮 X 秒”可查看股票请求、量比、本地数据、指数及界面耗时。股票和指数的请求耗时相互重叠，不能直接相加。刷新间隔控制尝试启动下一轮的频率，在途请求未结束时不会叠加新一轮请求；切换来源从下一轮起生效。
