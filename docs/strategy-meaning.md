# 打分策略与筹码策略

## 打分策略

打分策略按每只股票当日的行情、指标、资金流和筹码数据判断规则是否成立。规则可以加分、减分，或作为后续跟踪的起点；各项分值与跟踪分共同形成总分，用于比较同一天的股票。

规则分别描述趋势回调、洗盘、相对超跌、趋势启动、量价结构、相对高位、异动等不同形态。正分表示符合相应的观察条件，负分表示出现规则定义的风险或偏弱特征。具体条件、分值和有效天数以策略管理页各规则为准。场景把相关规则组合起来，依据配置的阈值展示观察、触发、确认或风险状态。

有些形态需要经过多个交易日才能判断后续发展。跟踪规则从指定事件开始，记录当时的参考价，继续观察守价、突破或收复等条件；取得的跟踪分单独显示，并计入总分。数据不足时，无法确定的规则不会凭空计分。

## 筹码策略

筹码策略根据历史价格和换手，模拟不同成本位置的库存及其变化，并将库存划分为模型主力和散户。它描述的是模型估计的成本与行为，不是实际账户持仓。

每天的换手决定有多少库存参与交易。卖出规则按持有人、价格形态和库存盈亏调整不同成本筹码的卖出倾向；新成交再按当日价格分布放入成本区间。独立买入模式以交易前的主力库存占比为基准，根据当日方向证据调整新增成交中主力与散户的比例。

方向证据综合放量突破、缩量守价、破位、冲高回落、区间位置等形态，以及价格、换手和指标的变化。正向证据提高主力买方比例，负向证据降低该比例；市场状态也可以调节证据或买入力度。部分失守条件会限制合并后的方向证据，避免其他正向条件掩盖失守。

成本规则还会区分亏损、回本、浮盈及利润回吐等状态，调整对应库存的卖出倾向。成本分布、主力占比和库存年龄随每日成交逐步变化，可供图表和打分规则使用。

筹码配置修改后，已有历史结果不会自动改变；需要在计算页重建筹码历史，依赖筹码的打分结果也应重新计算。单股计算和模式参数见[筹码单股测试](chip-testing.md)。
