# 研究回测与结果存档

在「统计回测 → 研究回测」中使用「策略研究」检查表达式，使用「排名对照」调整完整策略。策略研究可通过“导入策略”载入普通、组合及区间计分规则；组合规则显示可编辑的条件列表、命中计分、附加分和封顶。未导入时也能选择策略类型，从头编写普通或组合策略。普通规则也可在“编辑策略”中填写表达式；编辑区默认展开，收起后保留表达式预览。日期、持有期和回测指标直接显示，其他评价设置、参数研究和核心策略对照集中在一层“更多参数”中。

排名对照会自动载入当前策略；“编辑策略”默认展开，显示场景列表与规则编辑框，保留组合条件、区间计分和后续跟踪，不显示策略管理页的近期新增及总览计数。排名对照集中在研究回测页，原策略回测页只保留已有评分的统计操作。编辑、增删及启停只修改本次回测配置，点击“运行排名对照”后与正式策略比较；“恢复当前策略”重新载入正式配置。修改规则后应先在编辑框保存，再运行回测。

两种模式顶部均有“回测历史与对比”：先用“查看结果”打开一份历史记录，再用“对比结果”选择另一份，或将刚完成的回测直接与历史记录比较。对比读取已保存统计，不需要重跑；日期、持有期、评价范围和方向等条件不同时，仅并列显示数值，不计算差值。表达式比较要求相同周期、参数取值及信号组成；排名比较使用当前选择的成员池和分组。差值是两份历史统计的差，不是跨运行的成对检验，也不证明输入行情没有变化。

每次运行自动保存结果和配置；顶部按钮可保存草稿、另存结果或导入结果包。每条已完成记录显示时间、策略、区间和持有期摘要；选中记录后可在记录卡片里编辑名称与备注，保存直接更新该记录，不产生新编号，也不重算或改动原配置和结果。对比的两条记录可分别编辑，备注随结果包导入导出。旧记录的文字备注继续保留。分组统计、季度表现、稳健性诊断和正负样本通过结果区标签直接切换；保存、导入等操作直接显示，分组与统计参数在一层“更多参数”中设置。结果采用专业术语及就地说明，不展示全量逐股、逐日分页。正负样本与随机代表样本继续保留。策略模拟盘独立使用，只有启用“保存交易模拟候选池”或原本保留成员库的排名记录可直接带入模拟盘。

## 单策略研究

可以导入现有规则，或输入表达式及参数家族。普通、组合、区间计分规则均保存可编辑草稿，并复用原生评分器使用填写的分值与计分结构。可不导入策略，直接在“编辑策略”中选择“组合策略”并新增条件；名称、表达式、附加分、命中数得分及正负限制值均可修改。普通策略可编辑固定分值，EACH/RECENT 可改为区间字典；区间编辑器与策略管理页共用。修改后重跑，条件命中、附加分及封顶由原生逻辑计算，不合并成简单 OR 表达式。组合及开启后续跟踪的策略不使用 UNKNOWN 扫描；未开启跟踪的普通及区间表达式仍可扫描参数。后续跟踪与策略管理页共用编辑器，点击“添加跟踪”即新增并启用；每条名称旁可独立勾选启用或删除，停用保留配置，可新增多条或导入后修改；冻结值、观察步骤、步骤分、确认分及保分结束条件均可编辑。回测复用生产跟踪引擎，在“信号组成”中查看原始信号、每条跟踪及原始＋全部跟踪，各自保留统计和正负样本，默认显示合并结果。跟踪得分按已取得且仍有效的每日贡献评价，并非仅评价首次确认日；全为 0 分的跟踪不产生得分样本。研究回放不更新生产跟踪状态。主周期可以自定，默认只计算所选持有期；在“更多参数”中可额外计算3、5、10个交易日。多周期复用信号扫描，分别生成原生后验标签。完整策略基线诊断默认关闭，需要相关性等诊断时再开启；选择核心策略或原榜分数档时自动启用，保留本次隔离重算，不复用历史评分。关闭时不计算基线分数和名次，但仍临时计算股票日、信号及标签以生成同类对照；新页面运行结束只保留汇总与代表样本。

表达式参数及完整候选策略均可先保存草稿；草稿只保存配置，修改、复制和运行生成新编号。

运行前配置市值及一项MKT分组边界。边界递增，等于边界归入后一组；留空不分组。市值单位为亿元，沿用信号当日成交额／换手率估算，不能当作精确历史总市值。代码板块、上市资料及当前ST、行业、概念资料的历史覆盖限制随运行保留。MKT只读十项已落库指标，按配置签名、失效起点和已完成日期过滤；不重算替代指标，缺值单列。

「匹配对照分析」保存全周期的全样本、代码板块及运行前配置的市值、分数档和市场指标分组统计。对照为同日、同代码板块、同市值组和分数档内可计算但未触发的成员；未配置的匹配条件不启用，缺少已启用分组的资料时不放宽匹配。触发和对照身份先确定，再读取可观察标签。匹配收益差先在同日内计算，再日期等权；置信区间沿用日期块重采样。分组统计从保存的汇总读取，无需重新回测，也不保留可任意事后筛选的全部成员。

季度统计保存有效收益日、超额收益均值和 IC 均值，按年份查看，每次最多四个季度；超额收益以全市场为基准，与匹配对照的基准不同。参数扫描通过参数取值选择器切换结果，不再平铺全部组合。逐日序列仅在本次统计、分段检验及区间估计中使用，不随新页面结果永久保存。

正负样本和固定种子的随机代表样本继续计算、保存并展示。样本沿用按股票及触发次数保留代表记录的口径，图集不能用于估计总体成功率；行情图读取当前行情。收益分布保留汇总分桶，不展示全量股票日或日度记录表。

## 真正的排名对照

进入「排名对照」后，在场景列表中选择场景，通过规则的“编辑”修改表达式、分值、观察窗口及跟踪条件；也可新增或删除规则。修改保存后点击“运行排名对照”。候选是界面维护的完整配置，基线在每次运行时读取当前正式策略；上次候选不会自动成为新基线。

运行分别调用原生评分、跟踪重放和生产同分规则，不修改生产配置或评分库；联合修改独立计算，不相加单项结论。
比较包括全市场、固定基线前100／500／1000内部的IC、ICIR及分层差，各方案重排后的固定席位TopK、最近三个有效评分日TopK并集、新增与移除成员和覆盖。先选资格已知且符合要求的成员，再读标签，缺标签不补位；三日池保留今日无评分或标签的历史成员。可按代码板块、事前配置的市值及MKT分组查看；切片作用于已选席位，不重新在子池挑满K只。

收益按双方共同可观察日期成对比较。可观察成员均值与固定基线席位分母的净贡献分别展示；变动成员缺标签时净贡献不可计算。固定席位数不同时也不输出固定席位净贡献。季度日历覆盖不等于标签成熟或数据同源认证。

「控制核心策略后的收益诊断」仍是收益序列回归，没有重排规则；不能替代这个面板的排名增量。

## 区间、运行身份与恢复

日期块长、重采样次数、种子随运行保存。默认10日块、500次用于控制计算成本，可自行修改。描述性95%区间保留完整交易日轴和缺值位置；HAC滞后为持有期减一，少于20个有效日不输出推断。表达式p值诊断按本次参数组合及评价周期数校正；排名按本次展示的成员池、分期和切片家族校正。它们不能校正其他运行、事后切片或反复查看历史带来的选择偏差，不产生自动过关分数或最优参数推荐。

时间前推至少隔离持有期个交易日，再按原生实际标签末日收紧训练前缀，避免停牌等造成的长窗口跨入检验期。所有候选共用同一交易日轴与窗口；没有安全训练区间或样本不足的窗口仍保留并标记不足。

每次运行先建立运行记录，再提交结果；完成、失败、取消或异常中断都能追查。进程退出后重新打开列表会标记上次未提交的运行。恢复配置会创建新运行并完整重算，不复用无法认证输入的半成品。表达式及排名支持阶段取消，不能打断正在执行的数据库查询；研究和模拟任务在应用内串行执行。失败、取消和中断记录保留配置与错误，未提交的明细数据库及暂存文件自动清理；强制退出遗留在重新打开列表时回收。清理与运行、导入、导出通过文件锁互斥，已完成结果继续保留；无法确认旧版进程已结束时暂缓回收，清理失败会记日志并在后续打开列表时重试。

存档位于数据目录的 `research_runs_v1/<run_id>/`。新页面运行保存配置、名称与备注、输入身份、算法版本、覆盖信息、汇总结果和正负／随机代表样本。表达式研究的证据数据库仅供本次计算和聚合，成功汇总后清理；排名默认不写成员数据库，需要继续验证交易时可在“更多参数”启用“保存交易模拟候选池”。旧存档中的明细保留原样，另存旧结果仍按原有方式复制其已保存明细。

默认不认证运行期间输入一致性。可选择运行前后对所列文件做SHA-256校验，变化则不提交结果；应用内其他仓库操作在校验任务期间排他阻止。此检查不是数据库一致快照，不能证明所有外部写入、依赖或历史评分与输入同源。启用完整策略基线诊断的实验，其相关性及核心收益回归使用本次隔离重算基线，不再要求先写入历史评分库。重合、得分相关只使用表达式可计算且基线评分存在的股票日；未知窗口和缺评分不补零。可按季度查看共同覆盖，季度沿用全区间选出的最多20条相似规则，收益相关另报共同有效日。该基线需要额外计算时间，且仍不保证运行期间输入一致；旧存档及未创建研究存档的旧命令行路径保留历史评分限制。构建可通过 `LIANGHUA_CODE_REVISION` 嵌入代码版本；未嵌入时明确标记未知。

「导出结果」生成 `.lhresearch` 结果包，含可读报告、配置、汇总结果和代表样本；旧记录附带原来已保存的成员／标签数据库。导入会逐文件校验内容并生成新编号，不覆盖本机运行；没有完整行情的设备也能查看保存结果，图表和重新计算仍依赖本机输入。旧版仅摘要的存档继续可读，不会补造当时没有保存的样本。Android导入导出使用系统文件选择器的流式读写。

## 交易模拟

有成员数据库的历史排名记录可进入「验证交易」，或在模拟盘中选择该研究运行、基线／候选及TopK。新排名结果默认只保存统计；需要保存候选池供交易模拟时，在“更多参数”启用“保存交易模拟候选池”，命令行请求则设置 `retain_membership=true`。RANK、SCORE和候选成员来自存档，买卖表达式及行情来自当前数据；不混用当前相似榜S_RANK。保存的排名在收盘后可用，因此研究候选池必须使用次日开盘买入。当前评分库的旧当日开盘／收盘模式仍保留；若买点使用当日收盘信息，不能把它解释为当日开盘已可执行的信号。

开盘买入先占用席位，收盘卖出释放的资金到下一交易日才能用于开盘买入；持仓上限、涨停无法买入和跌停延后卖出沿用原执行约束。成本账户按剩余席位平分可用现金，不借款；佣金双边收取，另设卖出税费及卖出滑点，买入滑点沿用原参数。费率0表示本次未模拟该项，不代表实际无费用。

账户允许分数股，没有整手、成交量、盘口或真实排队模拟。持仓上限为0时没有有限席位预算，不生成成本账户；缺少完整持仓收盘路径时也不生成净值。未清仓持仓按收盘估值，停牌日沿用前次估值，尚未扣未来卖出成本。逐票收益及旧示意曲线与成本账户分开，不能将研究日均残差累乘成账户净值。模拟配置、成本账户、交易及所用研究成员独立存档。

命令行也可用同一排名实现：

```sh
cargo run -p lianghua-app-strategy --bin rank_comparison -- 请求.json 输出.json
```

请求使用排名面板对应字段，包含完整 `candidate_config` TOML；命令创建相同的运行记录；默认仅保存汇总，`retain_membership=true` 时另存成员明细，不写生产评分结果。表达式的既有 `expression_backtest` 命令继续可用。
