# 研究回测与结果存档

在「统计回测 → 研究回测」中使用「策略研究」检查表达式，使用「排名对照」调整完整策略。策略研究可通过“导入策略”载入已有规则，也可展开“编辑策略”填写表达式；编辑区默认收起，收起后保留表达式预览。日期、持有期和回测指标直接显示，其他评价设置、参数研究和核心策略对照集中在一层“更多参数”中。

排名对照会自动载入当前策略；“编辑策略”默认收起，展开后显示场景列表与规则编辑框，保留组合条件、区间计分和后续跟踪，不显示策略管理页的近期新增及总览计数。排名对照集中在研究回测页，原策略回测页只保留已有评分的统计操作。编辑、增删及启停只修改本次回测配置，点击“运行排名对照”后与正式策略比较；“恢复当前策略”重新载入正式配置。修改规则后应先在编辑框保存，再运行回测。

两种模式顶部均有“回测历史与对比”：先用“查看结果”打开一份历史记录，再用“对比结果”选择另一份，或将刚完成的回测直接与历史记录比较。对比读取已保存统计，不需要重跑；日期、持有期、评价范围和方向等条件不同时，仅并列显示数值，不计算差值。表达式比较要求相同周期及参数取值；排名比较使用当前选择的成员池和分组。差值是两份历史统计的差，不是跨运行的成对检验，也不证明输入行情没有变化。

每次运行自动保存结果和配置；顶部按钮可保存草稿、另存结果或导入结果包。每条已完成记录显示时间、策略、区间和持有期摘要；选中记录后可在记录卡片里编辑名称与备注，保存直接更新该记录，不产生新编号，也不重算或改动原配置和结果。对比的两条记录可分别编辑，备注随结果包导入导出。旧记录的文字备注继续保留。适用范围、季度表现、诊断和样本通过结果区标签直接切换；保存、导入等操作直接显示，分组与统计参数在一层“更多参数”中设置。全部样本分页仅在展开后读取。策略模拟盘继续独立使用，排名结果可直接带入模拟盘。

## 单策略研究

可以导入现有普通规则，或输入表达式及参数家族。表达式内部使用页面选择的正负方向，不使用生产分值大小。主周期可以自定，默认只计算所选持有期；在“更多参数”中可额外计算3、5、10个交易日。多周期复用信号扫描，分别生成原生后验标签。完整策略基线诊断默认关闭，需要相关性等诊断时再开启；选择核心策略或原榜分数档时自动启用，保留本次隔离重算，不复用历史评分。关闭时仍保存股票日、信号、标签与同类对照，基线分数和名次留空。

表达式参数及完整候选策略均可先保存草稿；草稿只保存配置，修改、复制和运行生成新编号。

运行前配置市值及一项MKT分组边界。边界递增，等于边界归入后一组；留空不分组。市值单位为亿元，沿用信号当日成交额／换手率估算，不能当作精确历史总市值。代码板块、上市资料及当前ST、行业、概念资料的历史覆盖限制随运行保留。MKT只读十项已落库指标，按配置签名、失效起点和已完成日期过滤；不重算替代指标，缺值单列。

「适用范围、同类对照与全部样本」按保存的股票日明细查询季度、月度和分组。对照为同日、同代码板块、同市值组、表达式可计算但未触发的成员；缺少市值不能参与市值匹配。未配置市值边界时不要求市值可用，只控制板块。还可在运行前设置原榜分数档边界，匹配同档未触发成员；缺原榜评分时不放宽分数档。研究页面启用完整策略基线诊断的实验会隔离重算一次当前基线，总分、名次及规则分项随实验保存，多周期共用这份基线；旧存档仍保留原来的历史评分来源标记。分数档使用保存的基线分数，不能替代实际候选组合的排名对照。触发成员与对照身份先确定，再读取各自可观察标签；没有可比较收益的层留空。匹配差先在同日内计算，再日期等权；股票日加权均值另列。

覆盖分开显示资格不符、资格未知、行情缺行、表达式不可用和触发后缺标签。缺标签继续区分评价区间末端未成熟、个股后续行情不足、无效行情或扣减资料缺失；这些类别不填零收益。标签有值时保存原生实际入场与标签末日。

点击季度或分组可进入相同运行的后端分页明细，再筛选失败、缺失或未触发样本。事后发现的局部可另存为探索分支，保留来源、筛选和完整明细，不能因此把该局部改称独立检验。明细默认折叠；展开后显示后验读数并可打开行情详情，也可关闭“显示后验与行情”遮住读数。详情图使用当前行情和配置，不能当作历史实验输入。原有按后验挑选的正负图集和固定种子代表样本继续保留；它们与全部股票日分页的抽样范围不同，不能用图集估计成功率。

## 真正的排名对照

进入「排名对照」后，在场景列表中选择场景，通过规则的“编辑”修改表达式、分值、观察窗口及跟踪条件；也可新增或删除规则。修改保存后点击“运行排名对照”。候选是界面维护的完整配置，基线在每次运行时读取当前正式策略；上次候选不会自动成为新基线。

运行分别调用原生评分、跟踪重放和生产同分规则，不修改生产配置或评分库；联合修改独立计算，不相加单项结论。
比较包括全市场、固定基线前100／500／1000内部的IC、ICIR及分层差，各方案重排后的固定席位TopK、最近三个有效评分日TopK并集、新增与移除成员和覆盖。先选资格已知且符合要求的成员，再读标签，缺标签不补位；三日池保留今日无评分或标签的历史成员。可按代码板块、事前配置的市值及MKT分组查看；切片作用于已选席位，不重新在子池挑满K只。

收益按双方共同可观察日期成对比较。可观察成员均值与固定基线席位分母的净贡献分别展示；变动成员缺标签时净贡献不可计算。固定席位数不同时也不输出固定席位净贡献。季度日历覆盖不等于标签成熟或数据同源认证。

「控制核心策略后的收益诊断」仍是收益序列回归，没有重排规则；不能替代这个面板的排名增量。

## 区间、运行身份与恢复

日期块长、重采样次数、种子随运行保存。默认10日块、500次用于控制计算成本，可自行修改。描述性95%区间保留完整交易日轴和缺值位置；HAC滞后为持有期减一，少于20个有效日不输出推断。表达式p值诊断按本次参数组合及评价周期数校正；排名按本次展示的成员池、分期和切片家族校正。它们不能校正其他运行、事后切片或反复查看历史带来的选择偏差，不产生自动过关分数或最优参数推荐。

时间前推至少隔离持有期个交易日，再按原生实际标签末日收紧训练前缀，避免停牌等造成的长窗口跨入检验期。所有候选共用同一交易日轴与窗口；没有安全训练区间或样本不足的窗口仍保留并标记不足。

每次运行先建立运行记录，再提交结果；完成、失败、取消或异常中断都能追查。进程退出后重新打开列表会标记上次未提交的运行。恢复配置会创建新运行并完整重算，不复用无法认证输入的半成品。表达式及排名支持阶段取消，不能打断正在执行的数据库查询；研究和模拟任务在应用内串行执行。失败、取消和中断记录保留配置与错误，未提交的明细数据库及暂存文件自动清理；强制退出遗留在重新打开列表时回收。清理与运行、导入、导出通过文件锁互斥，已完成结果继续保留；无法确认旧版进程已结束时暂缓回收，清理失败会记日志并在后续打开列表时重试。

存档位于数据目录的 `research_runs_v1/<run_id>/`。保存配置、假设、探索／检验区间、历史查看情况、输入文件身份、配置原文、数据覆盖与欠账状态、算法版本、结果和明细。历史结果与生产启用分开，另存结果复制原明细，之后可以独立删除来源。

默认不认证运行期间输入一致性。可选择运行前后对所列文件做SHA-256校验，变化则不提交结果；应用内其他仓库操作在校验任务期间排他阻止。此检查不是数据库一致快照，不能证明所有外部写入、依赖或历史评分与输入同源。启用完整策略基线诊断的实验，其相关性及核心收益回归使用本次隔离重算基线，不再要求先写入历史评分库。重合、得分相关只使用表达式可计算且基线评分存在的股票日；未知窗口和缺评分不补零。可按季度查看共同覆盖，季度沿用全区间选出的最多20条相似规则，收益相关另报共同有效日。该基线需要额外计算时间，且仍不保证运行期间输入一致；旧存档及未创建研究存档的旧命令行路径保留历史评分限制。构建可通过 `LIANGHUA_CODE_REVISION` 嵌入代码版本；未嵌入时明确标记未知。

「导出报告与明细」生成 `.lhresearch` 结果包，含可读报告、配置、结果及已保存的成员／标签数据库。导入会逐文件校验内容并生成新编号，不覆盖本机运行；没有完整行情的设备也能查看保存结果，图表和重新计算仍依赖本机输入。旧版仅摘要的存档继续可读，不会补造当时没有保存的样本。Android导入导出使用系统文件选择器的流式读写。

## 交易模拟

从排名对照进入「用保存的候选池验证交易」，或在模拟盘中选择已有研究运行、基线／候选及TopK。RANK、SCORE和候选成员来自存档，买卖表达式及行情来自当前数据；不混用当前相似榜S_RANK。保存的排名在收盘后可用，因此研究候选池必须使用次日开盘买入。当前评分库的旧当日开盘／收盘模式仍保留；若买点使用当日收盘信息，不能把它解释为当日开盘已可执行的信号。

开盘买入先占用席位，收盘卖出释放的资金到下一交易日才能用于开盘买入；持仓上限、涨停无法买入和跌停延后卖出沿用原执行约束。成本账户按剩余席位平分可用现金，不借款；佣金双边收取，另设卖出税费及卖出滑点，买入滑点沿用原参数。费率0表示本次未模拟该项，不代表实际无费用。

账户允许分数股，没有整手、成交量、盘口或真实排队模拟。持仓上限为0时没有有限席位预算，不生成成本账户；缺少完整持仓收盘路径时也不生成净值。未清仓持仓按收盘估值，停牌日沿用前次估值，尚未扣未来卖出成本。逐票收益及旧示意曲线与成本账户分开，不能将研究日均残差累乘成账户净值。模拟配置、成本账户、交易及所用研究成员独立存档。

命令行也可用同一排名实现：

```sh
cargo run -p lianghua-app-strategy --bin rank_comparison -- 请求.json 输出.json
```

请求使用排名面板对应字段，包含完整 `candidate_config` TOML；命令创建相同的运行记录及成员明细，不写生产评分结果。表达式的既有 `expression_backtest` 命令继续可用。
