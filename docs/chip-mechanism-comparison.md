# 筹码生成机制对照

在“筹码测试”页选择股票和日期，勾选“比较筹码生成机制”后点击“计算”。切换快照日期可查看当日对照，K线及筹码图仍显示当前规则。结果只保存在本次页面的临时结果中。

## 三种生成方式

三种方式使用同一份行情、价格网格、模拟起点和预热设置：

| 方式 | 处理 |
| --- | --- |
| 当前规则 | 使用页面里的完整规则，包括延迟归属修正 |
| 关闭延迟归属修正 | 仅移除 `confirm_after > 0` 的规则，普通买卖规则保持一致 |
| 等概率参照 | 不区分持有人买卖倾向，两组买卖权重全部相同，没有延迟归属修正；主力／散户容器没有身份含义 |

对照显示总平均成本、获利盘及最大累计分布差。累计分布差表示在相同价格边界上，累计筹码比例差异的最大值，以百分点表示。它衡量模型差异，不表示模型准确率。均价及差异使用未舍入分桶计算；获利盘沿用当前引擎的桶中点口径。

“当前规则”与“关闭延迟归属修正”的差异反映归属修正及其后续反馈。“当前规则”与“等概率参照”同时涉及买方分配和卖出倾向，不能全部归因于某一条规则。

## 初始未知库存

模拟开始前已有库存的真实成本无法从起点当天行情获得。为保持三模型可比性，普通对照读数沿用引擎的初值估计；中性参照同时单列尚存初始库存：

`未知比例 = 从模拟起点到当前日期的 product(1 - 当日TOR / 100)`

计算包括预热期间。零换手不会消除未知库存，累计换手达到100%也不等于初始库存全部消失。该公式仅适用于等概率出库、固定流通总体的参照，不用于估计当前差异化出库模型的未知量。

“已知成本均价”从参照中扣除初值估计，只对模拟期间成交形成且仍存活的成本计算；完全没有已知库存时显示 `--`。“包含未知成本的获利盘范围”按全部流通盘为分母，允许未知库存全部盈利或全部亏损。它没有把已知库存放大到100%，也不是统计置信区间。这里的“已知成本”仍使用日线成交价格分配假设，不代表账户实际买价已被观测。

## 交易和归属变化

当前规则与关闭延迟归属修正还会显示库存来源：两类归属分别拆成“初始残留”和“后续成交”。后续成交是模拟开始后买入且目前仍存活的库存，不是累计买入量。初始来源随同成本桶、同归属的实际出库比例扣减；归属修正仅改变后续成交批次的标签，保留来源，不产生新买入。来源数量也随库存归一化保持相同尺度。

来源记录随全精度分桶检查点保存。旧检查点缺少来源字段时仍可续算，但来源显示不可用，不按零处理，也不把续算起点重新当成初始化起点；从原模拟起点重放才可恢复完整分解。这项补充不要求立即重建已有正式库。来源只是固定总体下的模型账本，不是账户实际身份或成本观测。

展开“当日模型交易与归属变化”可查看两组筹码的买入、卖出，以及分别转归主力和散户的数量，单位为每100份库存。

归属修正只改尚存批次的标签，不产生新交易。它当天不改变总成本分布；由于两组卖出倾向可能不同，后续日期的总成本分布仍可能变化。

## 使用边界

对照采用无限售流通股换手率与固定流通总体假设，尚未纳入解禁、增发等总体变化，也没有实现账户成本或年龄驱动出库。遇到相关事件时，应先核对总体变化，避免将断点解释为行为机制。

结果包含流通总体核实状态，当前为“未经核实”，页面在对照读数之前显示。计算输入尚无完整的历史流通股本及公司行动资料，因此不会把某个区间标为已核实或无事件；显示的初始未知库存也不包含解禁、增发等事件引入的未知成本。旧页面缓存缺少核实状态时，同样按未经核实展示。

模拟起点由本次加载行情及预热天数决定，页面会显示实际起点。预热并不保证初始库存已清洗，也不保证本次测试与全历史生产结果相同。

对照额外串行计算两次，每日分桶生成后立即提取汇总并释放，只有当前模型保留历史分桶供绘图；勾选开关默认关闭。原生表达式运行时及当前模型的历史快照仍会随历史长度与网格数量增长，这项优化不代表固定内存上限。它不会保存规则或重建正式筹码库。

## 独立基础成本V1

每次单股计算都另外返回基础成本，不需要勾选机制对照。它独立于身份策略，使用同一日线成交分配和网格：已有库存按实际换手等比例扣减，再加入当日成交成本。它是日线成本代理，不是实际账户持仓。

- K为模拟期间成交形成、目前仍存活的成本质量，按全部流通总体计量；分桶不会重新放大成100%。
- U为没有确定价格位置的起点前库存，始终满足K+U=1。
- 条件均价仅对K计算，K为空时显示缺失；各桶中点处累计分布范围为`[累计K, 累计K+U]`，收盘价处为获利盘范围。这不是置信区间。
- 基础结果包含模型版本、模拟起点、前复权坐标与输入指纹。指纹仅用于本机结果核对，不是数据真实性认证。

所有股本变化统一采用比例继承假设：新增流通、解禁、送转、定增等都不再要求用户分类，也不在股本变化当天修改K/U比例；只继续执行当天实际换手迁移。这个假设不表示新增股份的真实成本已被观测，也不表示解禁持有人一定是散户。

基础计算仍用VOL/TOR及存储舍入精度作数据质量诊断。明显跳变只提示“疑似流通股本变化，按比例继承处理”；缺失成交量或换手率过小也会提示无法核对总体。这些提示不阻断K/U、条件均价和获利盘范围发布。明确的零量零换手日保持库存。

所有结果仍标为“条件估计／未完整核实”，不称已认证无事件，也不把日线成本代理称为真实账户成本。

## L2 成交证据

切换快照日期时，页面分别显示当日的主动净量、大小单净量和买方分档占比，以及包含当日的过去三个市场交易日均值。它们只描述成交行为，不合成“主力概率”，不作为额外库存，也不改变 K/U 或旧身份情景。

主动净量使用 `NET_MF_V / VOL`；大小单净量使用 `(B_LG_V + B_ELG_V - S_LG_V - S_ELG_V) / VOL`；大单买方占比使用 `(B_LG_V + B_ELG_V) / (B_SM_V + B_MD_V + B_LG_V + B_ELG_V)`。页面保留成交量、买卖量和买方分档合计等原始分母。有效零值与缺失分开；三日均值要求三个市场交易日均有完整观测，停牌或缺字段不会跨日拼接。

北交所主动净量的来源语义及零值退化尚未核实，因此该市场显示原始记录并标记为不可验证，不套用沪深解释。研究阶段使用的成交口径相容性带没有作为产品阈值发布，证据也不会自动修改归属权重。

基础分桶与未知量位于独立展示区；原K线筹码图、三模型对照、正式策略字段和已有检查点含义不变。此入口从模拟起点计算，不把页面分桶作为续算检查点，也不会自动切换生产模型或重建历史库。
