# 组件取舍

后续 agents 修改本组件时请继续维护本文件，只记录难以从代码理解的工程取舍；首次设计和普通 bug 修复不记，没有合适记录时不要硬写。

- 问题：下载分段提交或先删后补时，等到整轮结束才记录修复清单会留下源行情已变化、旧结果仍被当作可用的中断窗口；解决方案选择：前复权行情删除、单股写入、按日写入与相应清单共用事务，追加新日期记录后续待计算区间，覆盖或补写已有历史再记录筹码待修复股票并重置模型完成状态；解释：事务失败两者一同回滚，已提交阶段中断则保留记录供下次继续；覆盖记录按代码及日期判定，不逐字段比对，宁可对相同数据重复维护，也避免大规模数值对比成本。单股覆盖区间延至该股已有末日，按日覆盖包含旧数据中被删除、上游未再返回的代码，避免遗漏连续状态计算的影响。
