# 组件取舍

后续 agents 修改本组件时请继续维护本文件。

- 本 crate 是应用层最上层，只承载同时组合 chart、market、strategy 等能力的页面用例。
- 其他应用 crate 不得依赖本 crate；该单向约束用于阻止应用层循环依赖。
- 组合后端能力时直接依赖对应所有者，禁止重新引入后端或 UI 聚合门面。
- 股票详情和筹码策略留在这里，是因为它们同时组合多个能力，不适合塞回任一底层业务域。
- 只运行 `cargo test -p lianghua-app-facade`，不要因此触发全 workspace 测试。

- 问题：详情图无条件读取排名、相似排名和股票 CSV，实时刷新还重算全部自定义指标；解决方案选择：按图表编译后的输入字段加载额外数据，实时指标按发布名称及表达式赋值的依赖从后向前筛选，再按原顺序计算，仍使用完整历史；解释：自定义指标共用运行环境，前一指标赋值的变量也可能被后一指标使用，不能只筛直接引用的名称；只有发布结果会回填图表，内部赋值不能替代图表直接读取的数据库字段。保留完整历史是为了不改变 EMA/SMA 等递推结果；不缓存数据库结果，以免下载或重算后展示旧值。
