# 组件取舍

后续 agents 修改本组件时请继续维护本文件，只记录难以从代码理解的工程取舍；首次设计和普通 bug 修复不记，没有合适记录时不要硬写。

- 问题：只限制回测计算并发，仍可能在计算前常驻全部策略触发明细；解决方案选择：触发数据与稠密评分列均按 parallel_batch_size 同批加载、计算和释放，临时规则消费紧凑触发行；解释：该参数同时控制并发与数据峰值，提前物化所有规则的字符串明细会绕过其内存约束。

- 问题：残差行情读取在短区间受数据库往返限制，长区间又容易同时持有过多原始涨跌幅、ER 和残差；解决方案选择：以约 256K 行时序点为目标，在每批 128–512 股之间自适应读取并释放；解释：短区间增大股票批次减少往返，长区间缩小批次控制内存峰值。
